# Vayb

Anin atmosferini paylasmaya odaklanan, foto-oncelikli mobil sosyal uygulama.

Vayb; manzara, isik, mekan ve gunluk anlari sakin bir sosyal deneyimle bulusturur. Kullanicilar fotograflarini paylasir, anlara parilti ve kisa his izleri birakir, Vaybla'da yeni atmosferleri kesfeder ve birebir sohbet edebilir.

## Uygulama Durumu

Vayb App Store'da yayindadir.

## Ozellikler

- Foto-oncelikli akis, Vaybla kesif ekrani ve profil masonry gorunumu
- Parilti ve kisa his izi etkilesimleri
- Kullanici adiyla giris ve e-posta dogrulama
- Foto yukleme, kirpma oranlari ve konum onerileri
- Kaydedilen anlar, takip akisi ve bildirimler
- Birebir sohbet
- Gizli hesap, engelleme, raporlama ve hesap silme akislari

## Teknolojiler

- React Native
- Expo SDK 54
- Firebase Authentication
- Cloud Firestore
- Firebase Storage
- Firebase Cloud Functions
- Google Places API

## Guvenlik

Firestore ve Storage kurallari kullanici verilerinin sahiplik sinirlarini koruyacak sekilde yapilandirilmistir. Google Places anahtari istemciye eklenmeden Cloud Functions uzerinden kullanilir.

## Yerelde Calistirma

```bash
npm install
npm start
```

Bu depo gizli anahtarlar, test hesaplari, yerel ortam dosyalari ve imzalama sertifikalari icermeyecek sekilde hazirlanmistir.
